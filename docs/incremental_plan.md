# 增量实施计划

## 阶段 0

目标：

- 看懂现有代码
- 明确复用关系
- 明确目标架构
- 建立新项目骨架

输出：

- 阶段 0 报告
- 当前架构文档
- 目标架构文档
- 新项目目录骨架

## 阶段 1

目标：

- 单人视频开播闭环

只做：

- 摄像头视频采集
- H.264 编码
- FLV 视频 tag
- RTMP 视频发送
- SRS -> HTTP-FLV -> 观众端出首帧

不做：

- 音频
- 业务状态
- WebRTC

## 阶段 2

目标：

- 单人音视频直播闭环

只做：

- 麦克风采集
- AAC 编码
- 音视频交织
- 观众端音频接入
- 基础 A/V sync

## 阶段 3

目标：

- 直播业务状态接入

只做：

- 开播鉴权
- 直播间创建
- Redis 状态
- SRS 回调
- SSE 推送

## 阶段 4

目标：

- 1v1 WebRTC 主播连麦

只做：

- signaling
- offer/answer
- ICE candidate
- track 生命周期

## 阶段 5

目标：

- 双人连麦节目流合成

只做：

- 两路 RTC 流进入节目合成模块
- 统一节目流重新编码与发布
- 观众继续看一路 HTTP-FLV

## 阶段 6

目标：

- 扩展到 3 到 5 人连麦

只做：

- SFU 思路下的小规模多人模型
- 固定布局模板
- 清晰房间状态

## 阶段 7

目标：

- GStreamer 对照实现

只做：

- 对照学习
- 架构重构对比

不是为了：

- 推翻前面所有实现
